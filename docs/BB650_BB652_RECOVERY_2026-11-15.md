## Bounded architectural correction (0.5.29)

Keep chunk checkpoints and transcript artifacts separate: a failed partial
transcription has no complete transcript to export. Processing workflows now export
the checkpoint tree with the same 14-day private diagnostic retention and accept
an explicit checkpoint run ID for exact-episode restore. Restore includes original
and timing-repair directories, preserves other episodes, and retains fingerprint
validation. This makes partial recovery inspectable and selectable beyond the
latest evictable cache. It does not introduce a service, paid model, new retention
scope, or an unbounded retry policy.

Both Gemini retry loops now preserve the actual provider error when the shared
guard has already stopped requests, avoiding the useless sleep and misleading
replacement error. Cooldown, request budgets, attempt cap and source checks stay.

Recovery plan: one exact BB652 force after inspecting its failed timing repair,
reusing the retained transcript and cached repair children; one BB650 recovery
reusing the two original chunks. Keep defaults and inspect each outcome before any
continuation. Do not raise caps or disable coverage checks to obtain a green job.

Deployment and episode outcomes will be recorded after verification.
